# Priora Lite: our own offline triage model

**Gemini is the teacher; Priora Lite is the student.** A small model we trained ourselves that reads what a patient says (Urdu script, Roman Urdu or English) and predicts **SATS triage signs and the OPD department**, with **no internet**, in **~8 ms on a CPU**.

Hospital internet drops. When Gemini is unreachable (or a kiosk is offline), Priora falls back to Priora Lite automatically, so patients are still prioritised.

## Safety design (unchanged from the online system)
- The model predicts **signs**, never the colour. The same **deterministic SATS engine** assigns RED/ORANGE/YELLOW/GREEN.
- A hand-curated **red-flag lexicon** (critical phrases in 3 languages, with negation handling) runs alongside the model and can only **add** red flags.
- Pain intensity is **not** guessed from words: offline, the patient rates pain on a 0–10 face scale and the SATS rules use it.
- Borderline predictions → minimum YELLOW + nurse review. Offline results are marked provisional; the nurse confirms every colour.

## How it was built
| Step | Detail |
|---|---|
| **Teacher data** | Gemini 2.5 Flash generated **5,176** labelled patient complaints (Roman Urdu 1,958 · Urdu script 1,701 · English 1,517): typical and subtle presentations for each SATS sign, everyday complaints for every department, a boost set for 14 safety-critical signs in Urdu/Roman Urdu, and **contrastive hard negatives** (same words, sign absent: "khansi hai, khoon nahi aata"). |
| **Leakage control** | Exact de-duplication; train/val/test split **by generation batch** (paraphrase families never straddle splits); items too similar to our hand-written evaluation cases (char-gram cosine ≥ 0.8) removed (none found). |
| **Features** | Character n-grams (2–5, word-bounded; robust to Roman-Urdu spelling like *seenay/sine/seene*) + word uni/bigrams; TF-IDF, sublinear tf. 18,000 features. |
| **Models** | One-vs-rest logistic regression for 30 SATS signs (multi-label); multinomial logistic regression for department. Regularisation chosen on validation (C=8, balanced). Per-sign thresholds tuned on validation: **F2 (recall-first) for emergency signs**, F1 otherwise. Mutually exclusive signs resolved (e.g. controlled vs uncontrolled bleeding). |
| **Deployment** | Weights exported to JSON (5.2 MB, pruned |w| < 0.08); inference re-implemented in TypeScript (`lib/lite/model.ts`) and verified against scikit-learn (max probability difference 0.035, from weight pruning). Runs in Node or the browser. |

## Results
**Held-out synthetic test set**: 636 complaints never seen in training (includes hard negatives). Colour computed by the real SATS engine:

| | Colour accuracy | Under-triage | Over-triage | Sign recall | Sign precision |
|---|:---:|:---:|:---:|:---:|:---:|
| Model alone | 82.1% | 6.1% | 11.8% | 0.71 | 0.66 |
| Lexicon alone | 61.6% | 35.2% | 3.1% | 0.14 | 0.63 |
| **Model + lexicon (shipped)** | **81.6%** | **5.2%** | 13.2% | **0.74** | 0.64 |

Department accuracy (exact): 76.9%.

**28 hand-written evaluation cases** (written independently of the teacher; same set Gemini is scored on):

| | Colour accuracy | Under-triage | Department acceptable |
|---|:---:|:---:|:---:|
| Gemini 2.5 Flash (online) | 100% | 0% | 100% |
| **Priora Lite (offline)** | **85.7%** | **3.6%** (1 case) | **96.4%** |

The single under-triage is a thunderclap headache whose only sign is pain intensity, which offline mode gets from the kiosk pain scale instead.

## Honest limitations
- Trained on **synthetic** data generated by an LLM; real patient speech will differ. A hospital pilot should re-train on de-identified, consented intake text.
- The red-flag lexicon was written after seeing an early miss on one hand-written case (Urdu stroke signs), so Lite's score on those 28 cases is **optimistic**; the held-out set is the fairer measure.
- Offline mode is **text only** (no speech recognition) and does not produce the AI summary or syndrome tags.
- 5.2% under-triage is why offline results are provisional and always confirmed by a nurse. Gemini remains the primary path.

## Reproduce
```bash
npx tsx --conditions=react-server --env-file=.env.local --tsconfig tsconfig.json ml/generate.mts   # teacher data (resumable)
python3 -m venv ml/.venv && ml/.venv/bin/pip install scikit-learn numpy scipy
ml/.venv/bin/python ml/train.py                                                                     # train + export
npx tsx --tsconfig tsconfig.json ml/evaluate.mts                                                    # parity + evaluation
```
Files: `data/generated.jsonl` (training data), `data/test.jsonl` (held-out split), `model/priora-lite.json` (weights), `model/metrics.json`, `model/eval.json`.
